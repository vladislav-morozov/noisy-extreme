# noisyExtreme

This repository contains replication files for the simulations in 'Inference on Extreme Quantiles of Individual Effects in Panel Data'.

Paper can be found [here](https://arxiv.org/abs/2210.08524).
Online appendix with full simulation results can be found [here](https://vladislav-morozov.github.io/files/2_noisyExtremeSupplement.pdf).
